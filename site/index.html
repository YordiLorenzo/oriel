Fast, cheap computer use for Windows.

oriel is an MCP server that lets your AI assistant use the apps on your Windows PC. It reads each window as text instead of screenshots.

Text, not screenshots

Reads windows as text

Every control is one line with a short ref, taken from the accessibility tree that Narrator uses.

Leaves your mouse alone

Clicks, fills and selects go through UI Automation, so you can keep using the PC while it works.

Says what changed

Each action replies with the controls that appeared, changed or went away. No second look.

Careful by default

It acts as you, and only in windows it is allowed to use. SECURITY.md lists every limit.

  • Never types into a password field
  • Stays out of sign-in, UAC prompts and password managers
  • No shell and no file tools
  • Only your own MCP clients can connect

Set up

One exe, no admin rights. It works with any MCP client that starts a stdio server.

Need a Mac or Linux desktop too? oriel-vnc, in the same repo, works with any screen that runs a VNC server.

  1. Install

    Download oriel.exe, then run this in PowerShell in the download folder:

    .\oriel.exe install

    Not signed yet: if SmartScreen stops it, choose More info, then Run anyway.

  2. Add it to your MCP client

    In the same PowerShell window:

    claude mcp add --scope user oriel -- "$env:LOCALAPPDATA\Programs\oriel\oriel.exe" mcp

    In %USERPROFILE%\.codex\config.toml, with your Windows user name for <you>:

    [mcp_servers.oriel]
command = 'C:\Users\<you>\AppData\Local\Programs\oriel\oriel.exe'
args = ["mcp"]

    In claude_desktop_config.json, or .cursor\mcp.json for Cursor:

    {
  "mcpServers": {
    "oriel": {
      "command": "C:\\Users\\<you>\\AppData\\Local\\Programs\\oriel\\oriel.exe",
      "args": ["mcp"]
    }
  }
}

    In .vscode\mcp.json:

    {
  "servers": {
    "oriel": {
      "type": "stdio",
      "command": "C:\\Users\\<you>\\AppData\\Local\\Programs\\oriel\\oriel.exe",
      "args": ["mcp"]
    }
  }
}

    On the Mac or Linux machine. The PC needs OpenSSH Server with key login.

    claude mcp add --scope user oriel -- ssh my-windows-pc 'C:\Users\<you>\AppData\Local\Programs\oriel\oriel.exe' mcp

    Tested with Claude Code. The other configs follow each client's documented format.

  3. Try it

    Ask your assistant: Which windows are open?

Questions

More in the README, or open an issue.

How is it different from Cua Driver?

Both read the accessibility tree. oriel answers every action with what changed, so the assistant doesn't read the window again. On WindowsAgentArena that made tasks 30% faster and 38% cheaper with the same model. Cua Driver completed 4 points more tasks: 67% against 63%.

Is it safe to let an assistant use my PC?

In the windows it may use, it can do what you can. It won't type into password fields, stays out of sign-in, UAC prompts and password managers, and has no shell. An allow-list in config.json keeps it to the apps you name. SECURITY.md lists what it guarantees.

It isn't code-signed. Can I trust it?

The source is open, every release lists its hash in SHA256SUMS, and you can build it yourself with the C# compiler that ships with Windows. Code signing is first on the roadmap.

Does it work on a Mac or on Linux?

oriel.exe runs on Windows. From a Mac or Linux machine, your assistant can use a Windows PC over SSH. For the Mac or Linux desktop itself, use oriel-vnc, the second MCP server in the repo.

Does it send anything anywhere?

No telemetry and no update checks. Your MCP client sends what oriel reads to its model provider, as it does with anything else you show it.

How do I remove it? 
& "$env:LOCALAPPDATA\Programs\oriel\oriel.exe" uninstall

It removes what it added and lists each item. Then remove oriel from your MCP client. What oriel changes on your PC
