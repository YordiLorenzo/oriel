Fast, cheap computer use for Windows.

oriel is an MCP server that lets an AI assistant operate the apps on your own Windows PC through the Windows accessibility tree, as text instead of screenshots.

Download for Windows View on GitHub

Free · open source · Windows 10 and 11 · one exe · MCP

Text, not screenshots

Most computer-use agents look at the screen through screenshots and act by moving the mouse. Every step sends a picture to the model, and every click takes over the pointer you are using. Windows already describes each window as a tree of named controls, for screen readers such as Narrator. oriel reads that tree, hands it to the assistant as text, acts on the controls directly, and answers each action with what changed.

Refs and change reports

Every action says what changed

tree lists a window's named and actionable controls, one per line, each with a ref such as kqm17. The assistant acts on a ref directly, without searching again. Every action replies with what changed in the window.

  • oriel waits until the app has stopped reacting, using the window's own accessibility events rather than fixed sleeps.
  • An element keeps its ref while it exists, and a ref never moves to another element.
  • A name that matches nothing comes back with the closest names.

Acting

In the background, until it needs the keyboard

invoke, set, select and scroll act through UI Automation. They don't take keyboard focus or move the mouse, so you can keep working while the assistant does.

  • keys, click and drag send real input, for things with no accessibility action: spreadsheet cells, canvases, drawing.
  • They bring the window to the front first, check it is the right one, and wait for a pause in your own typing and mouse use.
  • An action takes 5 to 20 ms and reading a window 20 to 60 ms, measured from another computer on the same network.

Element actions

  • invoke
  • set
  • select
  • scroll
  • no keyboard focus taken
  • the mouse stays where you left it
  • works on a locked PC too

Real input, when needed

  • keys
  • click
  • drag
  • window brought to the front and checked
  • waits for a pause in your typing and mouse use
  • refused while the PC is locked

Safety

Kept away from passwords and sign-in

oriel controls a real desktop, so it is careful by default. In a window it is allowed to use, the assistant can do what you can, so an allow-list can keep it to the apps a task needs.

  • Password fields can't be filled, read or typed into.
  • The lock screen, sign-in and UAC prompts, Windows credential dialogs and common password managers are off limits.
  • No shell by default: no tool runs commands or reads or writes files, launch refuses command interpreters, and open terminals are off limits.
  • The daemon listens on loopback only, and every connection proves it holds your per-user key. The key itself is never sent.

One file

One small exe, on the PC or over SSH

oriel.exe is about 180 KB, with no dependencies: it runs on the .NET Framework 4.8 that Windows includes. Use it on the PC itself, or from a Mac or Linux machine over SSH.

  • No admin rights, no service, no driver.
  • An SSH session has no desktop, so there oriel mcp talks to oriel's daemon in your desktop session over loopback, and starts it if it isn't running.
  • No SDK needed to build it yourself: the C# compiler that ships with Windows is enough.

Launch, wait and batch

Fewer model turns

launch replies with the new window's tree. wait reacts to the window's own events instead of polling. batch runs a sequence of steps in one call, and its report covers the whole batch.

  • In Claude Code the tools load up front instead of behind a tool search, which saves a turn at the start of a session.
  • screenshot shows one window, for canvases, charts and games, and screenshot=true on an action adds a picture of the result without an extra call.

What it works with

oriel is built on Windows UI Automation, the interface Narrator uses. Anything that exposes it can be read and acted on.

Windows

  • Windows 11: tested
  • Windows 10, version 1903 or later
  • The .NET Framework 4.8, which Windows includes

Not yet: Windows 10 isn't tested yet. On a locked PC, reading and element actions keep working, but keys, focus, click and drag are refused, and Windows suspends Store apps such as Calculator and Settings.

Apps

  • Anything that exposes UI Automation: most desktop apps (Win32, WPF, WinForms), Store apps, and web pages in browsers
  • Chromium browsers and Electron apps, through their accessibility tree
  • Exercised in WindowsAgentArena: Chrome, Edge, File Explorer, LibreOffice Calc and Writer, VS Code, VLC, Settings, Paint, Clock, Calculator and Notepad

Not yet: canvases and games have no accessibility tree, so screenshot shows them and click and drag act on them. Apps running as administrator need an oriel that also runs as administrator.

MCP clients

  • Any client that starts a stdio MCP server
  • Claude Code: most of the testing
  • Codex, Claude Desktop, Cursor and VS Code: configs that follow their documented formats

Not yet: tested with clients other than Claude Code.

Other computers

  • macOS, Linux, or anything else with a VNC server, through oriel-vnc, the second MCP server in the repo
  • Screenshots scaled for the model, clicks in screenshot coordinates, keys, typing and a zoom for small text
  • Runs next to the assistant; nothing is installed on those machines

Pixels, not text: on Windows apps, oriel.exe is faster and cheaper. oriel-vnc is for what the accessibility tree can't reach.

Install and connect

oriel is a stdio MCP server: your assistant starts oriel.exe mcp and talks to it. Install it once for your Windows account, with no admin rights, then add it to your MCP client.

  1. Download oriel.exe

    Get it from the latest release. To check the file, compare Get-FileHash .\oriel.exe with the release's SHA256SUMS.

    Download oriel.exe

  2. Install it

    In PowerShell, in the download folder:

    .\oriel.exe install

    It copies oriel to %LOCALAPPDATA%\Programs\oriel and starts it. Add --autostart to start it at sign-in.

    0.1.0 isn't code-signed yet, so SmartScreen may show “Windows protected your PC”. Click:

    More info → Run anyway

  3. Add it to Claude Code

    In the same PowerShell window, which fills in the path for you:

    claude mcp add --scope user oriel -- "$env:LOCALAPPDATA\Programs\oriel\oriel.exe" mcp

    Then ask Claude “Which windows are open?”. It answers through oriel's windows tool.

Other MCP clients

Every client needs the same two things: the full path to oriel.exe as the command, and mcp as the argument. Replace <you> with your Windows user name, or paste the path install printed. Restart the client after editing its file. Only Claude Code has been tested; these follow each client's documented format.

Codex %USERPROFILE%\.codex\config.toml

[mcp_servers.oriel]
command = 'C:\Users\<you>\AppData\Local\Programs\oriel\oriel.exe'
args = ["mcp"]

Claude Desktop, Cursor claude_desktop_config.json, .cursor\mcp.json

{
  "mcpServers": {
    "oriel": {
      "command": "C:\\Users\\<you>\\AppData\\Local\\Programs\\oriel\\oriel.exe",
      "args": ["mcp"]
    }
  }
}

VS Code .vscode\mcp.json

{
  "servers": {
    "oriel": {
      "type": "stdio",
      "command": "C:\\Users\\<you>\\AppData\\Local\\Programs\\oriel\\oriel.exe",
      "args": ["mcp"]
    }
  }
}

From a Mac or Linux machine

claude mcp add --scope user oriel -- ssh my-windows-pc 'C:\Users\<you>\AppData\Local\Programs\oriel\oriel.exe' mcp

The PC needs OpenSSH Server with key login. oriel passes each call to its daemon in your desktop session.

oriel-vnc, any desktop over VNC ~/.config/oriel-vnc/hosts.json

claude mcp add --scope user oriel-vnc -- uvx --from "git+https://github.com/YordiLorenzo/oriel#subdirectory=vnc" oriel-vnc

Needs uv. List your machines in the host file; logins can come from an environment variable or a command. Set-up and tools.

To check it without a client: & "$env:LOCALAPPDATA\Programs\oriel\oriel.exe" call windows. To update, run install from the new oriel.exe. Everything oriel changes on your PC, and how to undo it, is in What oriel changes on your PC. Smart App Control, if it is on, blocks unsigned programs; you can build oriel yourself instead.

Questions

Anything else? The README has more answers, and you can always open an issue.

How is it different from Cua Driver and screenshot-based agents?

Screenshot-based agents read pictures of the screen and click at pixel positions. Cua Driver reads the accessibility tree as text too, with screenshots on request, and reads the window again to see what an action changed. oriel lists what changed in the same reply, element by element. In WindowsAgentArena round 9, oriel took about 30% less time per task at the median and cost 38% less per run; Cua Driver completed 4 points more tasks. The benchmarks have every round.

What can't it do?

Canvases and games have no accessibility tree, so oriel can only look at them with screenshot and act with click and drag. Apps running as administrator are out of reach unless oriel runs elevated too. On a locked PC, keys, clicks, drags and bringing a window to the front are refused. It has no shell or file tools by default, and it runs on Windows only.

What does it change on my PC?

oriel install copies the exe to %LOCALAPPDATA%\Programs\oriel. The first time it runs, it makes %LOCALAPPDATA%\oriel for its per-user key and settings. --autostart adds a logon entry under HKCU\...\Run. When a client connects over SSH and the daemon isn't running, a one-time scheduled task starts it and is then deleted. While the daemon runs, it listens on 127.0.0.1 on a port of its own. The full list says how to undo each one.

Does it send anything anywhere?

No. oriel makes no network connections other than between its own processes on 127.0.0.1: no telemetry, no update checks. Your MCP client does send what oriel reads (window titles, control names, the text you ask it to read) to its model provider, as it does with anything else you show it.

Does it need admin rights?

No. It installs for your Windows account only, with no service or driver. Don't run it elevated without a reason: that is only needed to reach apps that themselves run as administrator.

How do I remove it?

In PowerShell:

& "$env:LOCALAPPDATA\Programs\oriel\oriel.exe" uninstall

This stops the daemon, removes the logon entry if there is one, deletes the install folder and the settings folder, and lists what it removed. Then remove oriel from your MCP client's config.

Is it safe to let an assistant type?

Treat it like someone using your PC on your behalf: in the windows it is allowed to touch, it can do what you can. Keys, clicks and drags go only to a window that is verified to be in front, wait for a pause in your own typing and mouse use, and never reach a password field. Text may only come before a key that can move focus, so {TAB}secret is refused. An allow-list in config.json keeps it to the apps you name.
